# 公司动效

在当前工作区制作文件供本人下载。先明确产品、受众、用途、画幅、时长和素材；资料不足时使用明确的占位文案，不编造产品参数。默认做 24 秒、1280×720、24 帧的片子。每次运行命令都使用末尾提供的已安装 node 和 om 绝对路径，不依赖全局 om。

## 与视频剪辑的分工

本技能用 huashu-motion 的 HTML + GSAP 时间线创作短产品动效、标题、图文叙事和合成配乐。现有 dsh-video-editor（HyperFrames）负责已有视频的批量剪辑、字幕与批量变体。已有素材要剪辑或加字幕优先用 dsh-video-editor；本包不切换到其他渲染引擎，不引入 Remotion、guizang 或 baoyu-design 的素材和提示。

## 制作流程

1. 在工作区新目录执行 `om new 产品片 --template company`。模板复制中文字体、GSAP、logo 和时间线到项目。目录已存在时换一个新目录；不覆盖旧作品。
2. 编辑项目的 `index.html`。复用模板的 scene 标签与 `window.__timelines.film`。只用本地、获授权的素材，不链接网络字体、脚本或媒体。画面随时间线 seek 确定，不用随机数、定时器、实时动画或墙上时钟。动画属性优先用 transform 与 opacity。避免闪烁，禁止扭曲或拉伸 logo。
3. 执行 `om check 产品片 --source`，修复结构、脚本和缺文件问题。
4. 执行 `om still 产品片 --at 0,4.5,13,23`，亲自查看静帧。核对中文缺字、遮挡、留白、logo 与片尾停留；改完再截图。静帧和视频使用同一渲染路径。
5. 执行 `om render 产品片 --format mp4 --workers 2`。它按当前时间线合成配乐并编码。GIF 用 `--format gif`，GIF 无声音；要求配乐时必须同时交 MP4。
6. 查看成品并确认声画、时长、字幕和画幅；提供工作区 `out/` 成品下载路径。保留源文件、配乐与静帧供本人修改。检查未通过就说明未通过，不把文件存在说成验收完成。

## 品牌约定

主色为现有品牌深紫 `#170057`，主文字白色；浅背景用 `#f6f3ff`，辅助紫 `#b9a4ff` 只作强调。中文使用随包 Noto Sans SC（500/900），保留字体许可；不从网络加载字体。产品图片可补充产品本身的颜色，文字须清晰可读。

片头 0–4 秒显示品牌和一句主题；4–20 秒讲产品与价值；20–24 秒片尾显示品牌和一句行动提示，最后至少停 2 秒。模板 logo 原样复制 `zp-mark.svg`。参考已批准 pet.js 的小幅探头和落定节奏：移动 6px、旋转不超过 3°、0.6–0.8 秒落定。保留现有轮廓、深紫底和白头，不画新吉祥物，不引入豆子花叔。视频不用 pet.js 的随机眨眼与实时定时器，全部运动由暂停时间线驱动。

## 运行限制

网页版首版没有 `om studio`，不启动端口和预览服务器。口播、采样下载、素材抓取、分享上传命令均关闭；配乐完全在本地合成。需要口播时说明当前版本未提供，交由视频剪辑路径使用本人提供的现成音频。

同一容器同时只执行一个动效任务，渲染最多 2 个浏览器，编码线程最多 2；片长最多 30 秒，画面不超过 1920×1080 总像素（可竖屏），每项任务最多 5 分钟。出现“另一项任务正在运行”就等它完成；超时则降低分辨率、简化画面或改用视频剪辑，不循环重跑耗尽资源。这些是任务限额，不保证容器总 CPU 上限。

浏览器由部署的 `OM_CHROME` 直接指向共用 headless shell；Linux 启动参数由插件设置，无需编写 Chrome 包装脚本。ffmpeg 和 ffprobe 使用镜像已有命令。不要安装依赖、下载浏览器、模型或采样包。缺运行环境就报告缺哪项，保留已完成源文件，交管理员处理。
