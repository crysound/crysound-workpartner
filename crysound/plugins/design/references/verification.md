# 验证与未验收项

先用一个已知正确的本地 HTML 验证渲染工具是否可用，再相信设计截图。使用 `scripts/render.mjs`，只复用 `SLIDESTUDIO_PLAYWRIGHT_RUNTIME` 的 `launchPinnedChromium`。没有运行时即失败，禁止静默换用另一个浏览器或安装新依赖。

每次生成 PNG 和 report.json 后亲眼核对：中文字体、内容完整性、层级、重叠、裁切、观看距离与各方向的结构差异。脚本能检出的只有控制台/页面错误、破图、横向溢出、极小文字和远程资源依赖。全绿不等于审美、可访问性和业务交互全过。

点击验证用 `scripts/browser-runtime.mjs` 导出的 `withBrowser`，在回调里创建 page 并运行 Playwright 操作；该包装器管理浏览器关闭与两个全局槽。禁止在回调中自行 launch 浏览器。单次命令依次完成所有视口和点击路径，不并行创建大量 page。

网页验证 1440×900、375×812：导航、主要动作、展开、表单空白/错误态；App 验证详情、关键动作、tab、返回；海报验最终像素尺寸与缩小后可读性。所有输出检查键盘焦点、减少动态效果、文字对比度至少 4.5:1 和交互区至少 44×44px。脚本没有自动检测这些项，逐项记录人工/浏览器核对结果。

远程网络默认阻止。图片、字体或库触网会令报告失败，先改为项目本地资源。不要用联网素材或真实用户资料充当测试数据。输出应可断网打开。

未跑的项目写“未验收”并给原因与下一步；不能用文件存在、编译通过或脚本自报替代真实截图与点击证据。没有直接截图或测试结果时不要宣布验收通过。
