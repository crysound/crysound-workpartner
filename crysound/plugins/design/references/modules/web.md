# 网页与官网

首屏用题材世界里最有特点的内容开场，选择一句标题、一张真实产品图、可操作的演示或一个解释测量关系的信息图。只有适合内容时才用“大数字加渐变”或三栏卡片。先做三个不同叙事结构，再扩展用户选择的方向。

正文移动端至少 16px，辅助文字至少 12px，交互区至少 44×44px，对比度至少 4.5:1。导航、展开、表单状态与 tab 必须真的可点；原型动作使用演示数据。测 1440×900、375×812，查看完整页面，检查控制台与资源错误。用 `scripts/render.mjs`，不得下载浏览器或使用外部 CDN。

品牌默认读 DESIGN.md。需要窗口展示外壳可参考 `assets/browser_window.jsx` 与 `assets/macos_window.jsx`；这些是源码参考，不要求引入 React。优先自包含 HTML/CSS/JS，避免联网运行编译器。
