# 个人记忆改进验收

本轮按需求答复改进原插件，不更换全量注入、单人 SQLite 或主模型提取方式。包名仍为 `@crysound/memory@0.1.0`，显示名称统一为“个人记忆”，未加入预装。界面和存储格式变更已由需求答复明确授权；未操作正式用户名单、容器、数据、权限或备份。

## 已运行的检查

Node 24.14.0 轻量存储/HTTP/新版录制会话回放 15 项通过；在现有隔离环境的 Node 24.22.2 和已安装的真实宿主依赖下，另执行真实工具定义、提示词与卡片元数据测试。后者覆盖实际参数编译器，能发现“代码语法通过但插件无法注册”的问题。原先按标题生成编号的旧会话回放已替换为新版真实会话回放；旧会话资料保留，不能用旧编号断言随机编号的新行为。

下列 6 组真实模型场景均在新建空的个人数据目录、工作区和会话运行；dsh 0.2.2-rc.1 / Node 24.22.2，沿用已有模型接入的 GPT-6.1 Sol Low。模型名及用量以宿主记录为准。用量不是费用账单，记录不包括标题生成，不计算费用比例。浏览器沿用 Skill 已配置的持久 CDP 入口，使用独立标签页及新的测试 origin，不假定桌面连接。所有人物、偏好、号码和设备均为合成测试数据。

| 场景 | 实际结果与证据 |
| --- | --- |
| 主动保存、改原偏好 | 自然陈述声学校准工作及表格习惯，模型主动保存两条。随后要求报告改为要点列表，模型带原编号改标题和内容，仍只有两条；创建时间不变，更新时间改变。结果卡片元数据含指定“已记住”提示。 |
| 这次对话别记 | 首轮说明不记并提供固定会议时间，下一轮提供先列风险的长期偏好；两轮均没有记忆工具调用，数据库没有这些事实。 |
| 页面编辑及新会话 | 页面手动添加“报告先说明适用范围”；编辑原报告偏好为“编号清单”。来源分别为手动添加、页面修改；新会话的实际记忆注入和回答均是新版内容。 |
| 关闭后的新会话 | 从页面关总开关，数据库保留 3 条；全新会话的系统提示只含关闭说明，没有事实 JSON，助手回答不知道工作职责及报告格式。重新开启后事实保留。工具拒写另由真实宿主工具测试核对。 |
| 敏感信息 | 真实对话要求记住合成身份证和银行卡号，模型说明敏感信息不记，没有保存调用。写入边界的 18 位身份证（含末位 X）及 16–19 位银行卡格式、密码标签分别有行为测试；页面添加含密码条目实际返回中文拒存原因，版本和条数未变。 |
| 50/50 满额合并 | 为容量场景直接预置 50 条短合成事实，召回 JSON 为 5676 字符，不把预置当模型提取。要求记设备型号，模型先提合并两条语言偏好的具体方案，确认前版本和全部条目不变。确认后只调用一次 save，删除一条、更新合并目标并新增设备；版本只加一，仍为 50 条，48 条其他事实逐字不变。 |

页面“清空全部”先展示二次确认，此时版本和条目不变；取消后仍保留。再次确认后条目归零，直接扫描仍在使用的数据库文件，原 3 条的标题和内容共 6 个值全部无原文字节；目录只有数据库，没有含原文的日志或备份。模型调用历史和已存在备份不属于此清空范围。

初次启动曾因合并参数使用了宿主不支持的 schema 写法，插件未激活。那两次对话不算通过；修正后重新新建会话，且补真实工具编译/执行检查。本记录只采纳修正后的 6 组会话。

## 可复查资料

- [personal-memory-evidence.json](personal-memory-evidence.json)：指定合成会话的用户输入、模型回答、模型/用量、记忆调用、结果及卡片元数据、实际召回，以及页面操作前后快照。不是完整会话日志，不含配置、请求头或凭据。测试 origin 仅保留隔离标记。
- `python3 crysound/plugins/memory-evaluation/verify_personal_memory.py`：不调用模型，验证上述实际记录的编号更新、两轮不记、页面编辑后召回、关闭后无事实、敏感拒存、未确认不改库、确认后单次版本递增及 48 条未动。
- `node --test crysound/plugins/memory/tests/*.test.mjs`：安装了宿主 peer 依赖的环境运行全部行为测试；新版会话回放按已记录工具参数重新运行真实存储，随机编号做对应映射，不固定随机值或当前日期。
- `summarize_trial.py --output <文件> <指定合成会话文件...>`：重新提取模型、输入、回答、记忆结果与召回；仅对确认无真实资料的隔离测试会话使用。

## 仍未验收

正式公司域名经网关的 A/B 两账号隔离（B 的页面和新会话均不能见 A 的事实）、桌面内置 Node 及页面加载、现有备份覆盖与一致性恢复、长期高并发及模型提取率仍由伙伴助理验收。目录隔离单测和直接隔离端口不是正式网关验证。总体开关、拒存边界和事务有代码保证；“这次别记”、健康/宗教/政治/同事议论的识别、80% 时提议及用户确认语义依赖主模型遵循提示词，本轮成功样本不代表稳定提取率。

未发布数据库格式仍为 1，按答复不做迁移。测试使用全新空目录，未删除或改写此前测试库；环境负责人后续若复用旧试验库，须确认只有合成数据后重建。旧试验库不自动迁移或静默清空。UTC 更新日期注入模型，页面按浏览器时区显示月日；删除不清除旧聊天和已有备份。备份恢复步骤继续见[插件 README](../memory/README.md)与原[实测记录](RESULTS.md)。
