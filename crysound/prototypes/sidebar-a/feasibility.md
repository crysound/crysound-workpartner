# 侧栏方案 A：可行性说明

## 核实范围与结论

本说明依据本轮实际网页版、浏览器已加载的插件代码、主仓库侧栏与工作区源码、品牌注入和现有发布脚本。基线为 `7b8533b3fc`。所有修改建议均为后续开发方案，本次没有实施这些修改。

方案 A 可以实现，单靠品牌 CSS 不够：布局与颜色适合放品牌层，搜索命令、按工作区数量选择列表、更多会话展示和插件页面合并需要组件或插件改动。优先利用既有插槽和服务；确需改变 dsh 组件的地方做小范围、可核对的包补丁或源码修改。不要通过搬运 React 管理的 DOM、伪造点击、长期依赖散列类名来替代组件逻辑。

## “我的工作台”到底是什么

实际浏览器加载模块 `@local/my-workbench`，不是飞书机器人插件、dsh 内置工作区，也不是兆华作品插件。客户端代码以 `my-workbench` 注册 `main` 页面和 `sidebar.panellist` 入口（`order: 25`）。观察到三类读接口：`/api/my-workbench/tasks`、`agenda`、`projects`，页面每 5 分钟刷新，并有手动刷新及分区失败重试。

页面实际包括：飞书未完成待办（截止时间、逾期提示）、今天到周日的日程、项目数与金额合计、阶段统计、未来 7 天跟进表。当前该模块客户端把日程时区写为东京时间，不能因为导航合并而悄悄改掉。工作台源码不在本轮主仓库检出内；仅凭此账号页面和加载模块，不能认定它已向全员预装或已支持桌面版。

“作品”当前由加载中的 `dsh-claude-artifacts` 插件提供，页面有幻灯片、设计、看板、设计系统、动画类别与已有作品。插件使用 `joinArtifactsPage` 协调作品页所有者，不能再随意注册一个同名页面覆盖它。公司正在使用的官方 `@crysound/artifacts` 对应关系见 `crysound/config/plugins.json`；正式开发必须核对目标账号实际安装版本，不能只补旧包名。

建议按已选方案 A 合并**导航**：侧栏仅“作品”，里面分“创作成果”（默认，保留原作品页分类、新建、打开和编辑）与“工作概览”（承载原工作台待办、日程、统计及跟进表）。两者数据保持分离；不把待办或日程转换成作品，不迁移、删除个人数据，不新增权限。未安装工作台模块的人只看到创作成果，不额外预装插件、也不出现坏入口。原型中用虚构卡片说明层级，金额表等未逐项重画，正式开发必须完整保留。

语义代价是“作品”不直观地暗示日程和待办，建议负责人重点实点第二个页签。若评审认为不合适，替代方案是在个人菜单保留独立“工作概览”，保持侧栏四入口；不要自行把侧栏扩成五个入口。本轮不据此改变产品方向。

工作台桌面后端和插件分发方式是正式开发前置核对项：先由伙伴助理定位现有模块来源与桌面数据通路，再决定抽出可复用面板或包装现有组件。尚无依据保证该工作台内容在桌面同样可用；本轮未请求登录、凭据或接管服务器。

## 发布与跨端注意

网页版 Dockerfile 安装固定发布版 `@deepseek-ai/dsh@0.2.2-rc.1`，不是把本仓库 `packages/` 直接编进镜像；只改上游 TSX 源码不会自动改变线上网页。品牌 JS / CSS 两端已经注入，但品牌层不能替代列表与页面逻辑。

后续可优先做一个有版本匹配检查的共享包修补脚本（类似现有市场补丁），在网页版运行时安装后和桌面打包运行时应用**同一份**补丁，并在实际安装副本上跑两次验证幂等。现有 profile 的 `plugin-patches.mjs` 不等于一定能命中全局安装的客户端包；需明确脚本输入目录、包版本、原文命中和修补后的行为。若压缩包补丁无法小而清楚地维持，则改源码并构建两端可消费的公司版组件包；不要静默放行未命中的修补。也可上游提交通用扩展点，等发布后再去掉临时补丁。

本次不选择或实施发布路径，不改工作流、不消耗构建分钟、不改网关或镜像。正式实现上线由伙伴助理另行安排，桌面需要新客户端发布，不能把“共用源码”写成“已验证在已安装的桌面版生效”。

## 正式开发应逐项验收

1. 单工作区（包括真实无归属会话）、多个工作区、自定义分组 / 子工作区、从多个变回一个，均找得到原会话，目录与归属不变。
2. 会话重命名、置顶、归档 / 还原、拖动、运行 / 等待 / 未读状态、内容搜索和搜索定位仍然有效；没有创建权限时不显示新建操作。
3. 市场 / 自动化 / 作品原功能可达；额外安装的插件不被一刀切屏蔽；工作台缺席、未授权、加载失败和重试可理解。
4. 作品内创作页与工作概览的数据及错误状态相互独立；原工作台金额、阶段、跟进表与自动刷新完整保留。
5. 相同窗口与样例下重新计算完整可见行数；浅色、深色、手机、收起、键盘导航、系统缩放与长中文标题检查。
6. 实际网页版下载可达，实际 Electron 无下载入口，Mac / Windows 顶部窗口控制与搜索快捷键正常。以上为后续验收清单，本轮只验证静态原型。
