# 侧栏方案 A：结构评审原型

这是需求 #127 的评审材料。只在本目录新增静态文件；线上界面、网关、镜像、个人数据和正式桌面应用均未修改。确认后另开正式开发，不把此原型接入产品或直接上线。

## 打开与点击

可以直接用浏览器打开本目录的 `index.html`。若要同时看对比页、复跑截图，在仓库根运行：

```sh
python3 -m http.server 8127 --bind 127.0.0.1
```

浏览器打开 `http://127.0.0.1:8127/crysound/prototypes/sidebar-a/`；对比页是同目录的 `compare.html`。不需要装依赖、登录或密钥。保留目录关系，原型直接引用 `../../brand/zp-mark.svg` 与小尺寸标志。

- 顶部搜索：点击放大镜，输入“产品”；点结果切到对应示例对话。`Ctrl/Cmd+K` 也可打开，`Esc` 关闭。原型只搜示例标题，正式版应接回现有全文搜索。
- 固定入口按已定顺序排列：新对话、作品、自动化、市场（小字“插件·技能”）。作品页只放创作成果，没有工作概览页签。首页主区域只是交互背景，不是本次首页改版提案。
- 插件入口在市场之后、最近对话之前。默认一个“我的工作台”，它是个人插件示例，不是同事预装，也不放个人菜单。按示例安装先后排列；1–2 个直接展示，超过 2 个时全部收进“更多”，展开可打开每个插件。
- 最近对话：点标题打开示例，悬停可见更多操作的占位说明；标题旁的显示选项可改变排序、显示示例归档会话。会话的分组、置顶、归档等正式操作未在原型实现。
- 个人菜单：网页版有“下载客户端”；右下角“查看方式”切到桌面版后隐藏。设置与下载仅提示目标，不打开实际设置或下载文件。
- 查看方式：切换深浅色、网页 / 桌面场景、单 / 多工作区，以及 0 / 1 / 2 / 3 个插件入口。链接加 `?plugins=0` 可直接查看无个人插件的同事场景，`?plugins=3` 可直接查看“更多”。只有多个工作区时出现分组；不修改或保存真实设置。
- 收起后保留搜索、固定入口和插件入口图标；手机上点左上角打开导航抽屉，点入口、遮罩、收起或 `Esc` 关闭。抽屉与搜索支持键盘焦点管理。

全部记录为虚构示例；发送按钮不发消息。不会调用业务接口或写入存储。

## 可行性与自查

详见 [feasibility.md](feasibility.md)。浏览器检查记录在 [verification.json](verification.json)，可用以下命令复跑交互检查并重拍五张图（现状裁图沿用初版采样（当前对照是历史基线，不代表重新拍摄的最新线上），不重新读取线上）：

```sh
# Chrome 已开本机远程调试；先创建自己的空白标签页并取得编号。
# 使用 Node 24 或更新版本；命令会导航这个标签页。
CDP_TAB=<自己的标签页编号> node crysound/prototypes/sidebar-a/capture.mjs \
  http://127.0.0.1:8127/crysound/prototypes/sidebar-a/
```

`CDP_ENDPOINT` 可指定已有浏览器的调试地址，默认 `http://127.0.0.1:9222`。脚本不创建新浏览器、不接管其他标签页、不处理登录；完成后自行关闭专用标签页。本轮沿用手册明确配置的持久浏览器入口，不依赖桌面应用连接。

已检查 JS 语法、实际浏览器交互、截图、资源加载和窄屏溢出。按需求单手册未安装依赖、未跑全仓检查、未打包或建镜像。真实全文搜索、真实会话菜单、真实插件安装与持久排序、自动化执行、客户端下载、实际 Electron 应用和正式发布均未验收。个人工作台后端不在本单范围。
