# 每天帮我查一次

网页设置中的自愿开关，默认关闭。复用本人飞书授权，周一至周五默认北京时间 09:00 检查未读 @、今天和明天的主日历日程、本人未完成任务。时间可改；当天错过时间会补查一次，不补历史日期，也不跟随中国法定节假日调休。桌面本机模式不另起任务，首版在网页版设置和查看。

只有新的或内容发生变化的待处理事项才调用模型；空结果及与上次相同的事项不调用模型、不建对话、不提醒。模型只接收收集的数据，没有工具、发送消息、回复或操作飞书的能力。摘要放进一条“伙伴 · 日期 提醒”对话，网页侧栏底部显示未读入口。它不依赖侧栏固定“伙伴”原型；不发送飞书机器人消息。

## 状态与重启

网关是运行状态的唯一写入者；每人独立记录文件，文件名由本人标识计算散列，权限 600。新目录是 `/state/daily-check`，不更改用户名单、密钥或会话格式。

每次读飞书前先持久记录当天尝试。同一人同一天（包括手动检查）最多尝试一次；失败或崩溃不自动重试。设置中保留最近 30 次记录，失败原因以 `read` / `summary` 阶段记录，客户端按界面语言显示；不会保存原始错误正文。读取被截断、身份不是本人、无法核实已读状态时按失败记录，不能按“没有新事”处理。首次启用会检查全部可获取的未读 @ 和未完成任务；后续对照上次成功检查的事项指纹去重。

模型调用前保存输入事实（最多 60,000 字符），待投递摘要有预先分配的会话和消息身份。Host 读待投递摘要，使用原生会话接口追加一条模型消息并确认持久化，再回执完成；确认丢失后重投按消息身份去重，不重新调用模型。不向 Agent 提交 prompt。关闭、断开授权或撤出试用后不再投递待处理摘要，已送达的历史对话保留。

## 部署与验收

界面及新增个人运行记录已通过分诊审查；交伙伴助理先部署测试账号的网关和个人容器镜像，真实验收通过后才加 `deliver` 标签。新增模块由 compose 挂载到网关，镜像中的原生设置通过现有 profile 准备流程更新。

在 `crysound/web/.env` 配置：

- `DAILY_CHECK_USERS`：允许试用的已开通用户 slug，以逗号分隔；默认为空，无人可启用。先仅开放指定测试账号用于验收，随后只开放本人试用一周，再决定推广。
- `DAILY_CHECK_MODEL`：公司模型清单中的实际模型 ID，默认为空。使用该人的现有模型网关钥匙计费，不新建钥匙。

这些参数同时见 `.env.example`；本人仍须在设置中手动打开。需要已启用本人飞书授权，容器中的官方 CLI 1.0.99 已提供消息搜索和本人已读状态查询，不增加权限或更换凭据。收集器只执行固定只读命令，均带 `--as user`，使用飞书包装器按调用领短期令牌。

先用指定测试账号授权并启用，点“现在查一次”：有新事时应生成一条可打开的对话并显示未读入口；再次打开不重复追加；无新事时不调用模型、不产生对话；关闭或断开时不运行。核实跨本人隔离、重启后不重跑、失败记录可见、周一至周五及北京时间可改。首版不验收飞书机器人推送。

## 本轮证据

- `node --test crysound/daily-check/service.test.mjs crysound/feishu/native.test.mjs crysound/web/gateway/tests/feishu.test.mjs`：固定时钟与临时目录的状态行为；真实 HTTP 与 Docker socket 适配边界；Host 投递协议替身测试；现有授权回归。
- `node --check`：改过的 JS / MJS。
- `verify-browser.mjs`：沿用规则配置的持久浏览器，必须传入本人创建的 `CDP_TAB`；只在该页注入分支设置模块，并将所有每日检查与飞书请求接到隔离测试服务。真实原生设置壳和控件，后端为此分支真实 HTTP 处理器，数据为空的测试夹具；截图在 `evidence/`。

截图和浏览器结果证明设置交互、默认关闭、告知文案、时刻保存、重复运行拒绝、未连接入口和无新事静默。它们不代表已经对真实飞书账号完成读取，也不代表真实 Host 持久化和模型转发已经验收。本轮未装依赖、未建镜像、未构建桌面版、未修改线上用户。以上真实账号与 Host 集成项目交伙伴助理在测试环境核对。

设置导航、告知、控件、运行结果、错误提示与未读入口沿用同一套中英文字典和语言绑定。`PREVIEW_LANGUAGE=en` 在本人标签页中临时将注入模块设为英文字典，用于核对原生控件，不修改已保存的界面语言。HTTP 失败响应提供稳定 `code`，客户端翻译错误，不直接展示远端正文。容器 stdout 先合并 Docker 帧字节，再统一解码 UTF-8；跨帧的中文和表情保留，截断帧报错。
