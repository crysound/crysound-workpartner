`plugins.json` 的可选布尔字段 `missingOnly` 表示只补缺失依赖；省略或 false 时继续核对固定版本。网页和新桌面版均保留创作插件任何已装版本，包括更旧、更高、非标准规格；不重装、不自动升级或降级。停用选择不变。沿用官方插件规则：原生管理页拒绝卸载，允许停用；若本人用终端移除依赖，下次启动会补装。

侧栏只保留公司作品面板，搜索后为作品、自动化、市场。五个创作插件按注册归属隐藏，上游作品入口按稳定 id 隐藏；不卸载插件、不迁移目录、不改变任何作品和启用记录。页面中文名称通过启动修补统一为“作品”，市场包元数据不变。导航修补在已有 v1/v2 产物上可增量应用，已核对与 #154 两种顺序的最终模块行为一致、重复执行不变。

## 检查证据

本地使用 Node 24 跑实际网页安装循环的临时 profile、桌面准备函数和固定发布版浏览器模块；包管理过程使用假安装器，无网络下载或真实用户数据写入。新建、部分已装、失败重试、重复启动、保留新旧版本、停用选择、原有作品文件、页面文案完整修补和幂等均通过。命令：

```sh
SIDEBAR_RUNTIME_MODULES=<原始固定版 node_modules> ARTIFACTS_CLIENT=<作品1.0.0的lib/client.js> node --experimental-vm-modules --test --test-isolation=none crysound/scripts/tests/sidebar.test.mjs crysound/tests/desktop-market-plugins.test.mjs crysound/tests/creation-preinstall.test.mjs
```

浏览器仅在手册的持久浏览器专用标签页替换分支响应，不是已发布镜像。姓名和对话标题经过遮罩。页面“作品”名称、打开原生作品页、新建区域列出五个可用创作技能，以及浅色/深色的展开/收起导航为核对范围；截图和最后一次运行结果在本目录。页面切换与收起切换直接调用原生按钮的 click，未把坐标点按称为已验证。复跑命令：

```sh
CREATION_SKIP_MOBILE=1 CDP_TAB=<专用标签页> SIDEBAR_EVIDENCE_DIR=<证据目录> node crysound/scripts/tests/creation.browser.mjs
```

先前尝试手机时未出现原生抽屉开关；一次桌面尝试捕获到页面连接重试，未将那些尝试记为通过。最终桌面复跑记录单独保留。手机截图与触控行为仍待发布环境核对。浏览器预览没有真实新建作品；作品页原生“新建”打开技能提示词草稿，生成作品之后才有编辑器，因此四类新作品编辑器加载仍待验收，不因新建入口可点而算通过。

## 部署与启动时间

先同步完整公司配置，再重建伙伴镜像，按既有更新规则换容器；桌面随下一安装包带入新准备逻辑与导航补丁。发布前须在测试账号新档案和已有档案真实补装、重启复核，再安排其他账号。旧桌面准备程序不识别 `missingOnly`，不能宣称同步配置就给旧安装包提供保留已装版本的语义。

首次最多增加六次串行市场安装，已有六项则不调用这些安装命令。实际下载与启动增量尚未实测；本地假安装器时间不代表线上耗时。桌面沿用单项最多 120 秒、总安装预算 180 秒，未完成项下次启动重试；预算还包含原有在线安装，首次不保证一次装齐。网页沿用安装器重试策略，没有本次新增的总时限。实际首启耗时与网络失败时的体验列入发布验收。

回退需同时还原公司配置并换回上一镜像/桌面包，停止补装和恢复旧导航；保留已安装六包及所有作品，不自动卸载。启动修补已缩短的页面文案会留在现有包副本中，直到该插件后续更新替换文件；回退不保证把已修补文案改回旧称。
