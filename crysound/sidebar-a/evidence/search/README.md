## 配色与品牌行追加要求复核

本目录的十八张截图已更新为追加要求后的预览。[2232×1184 并排图](cindy-side-by-side.png)与提供的参考图尺寸相同：左侧为新版网页侧栏，右侧只裁出参考图中的 Cindy 侧栏；两图保留纵横比后置于同一画布，不包含原图左侧的私人对话。它比较底色与墨色，不声称 dsh 与 Cindy 的导航、会话结构或渲染尺度完全相同。[品牌行前后图](brand-before-after.png)只裁原图品牌行，与新版网页预览并排；不含真实会话内容。

浅色网页/Windows 侧栏取 `#E0E0DC`：参考图中 Cindy 侧栏的无文字区域（原图像素 x=900、y=650 起，200×250）RGB 各通道中位数为 (224,224,220)。深色没有提供实际对比截图，取 `#080808`：Cindy 深色 85% 黑色 5 合成到页底 24 后为 7.85，四舍五入为 8。这个近似取决于背景，不能承诺与所有桌面壁纸上的毛玻璃视觉一致。Mac 仍使用源码 `windowBackdrop.ts` 的 `rgba(238,238,233,0.85)` / `rgba(5,5,5,0.85)`，实际系统毛玻璃需安装包验收。

色板 126 项声明后的注释指向 Cindy `d920573a` 的源 token；检查脚本直接读取其 `cindy-light.ts` 与 `cindy-dark.ts`，校验原值和两种 Mac backing。六档文字保留透明墨色：浅色黑 88% / 95% / 70% / 56% / 44% / 32%，深色白 82% / 100% / 66% / 55% / 40% / 30%；分别映射主文字、强调、较次要、次要、三级和占位 token。浅色开关滑块的源值是 `hsl(var(--background))`，在此解析为该主题的 surface。故意把浅色页底改成白色时检查失败，未将错误副本提交。

选中胶囊和前景使用 `sidebar-item-active` / `sidebar-item-active-foreground`，与通用按下态 8% 分开；浅色为近白胶囊，深色为中灰胶囊。功能色以追加要求为准：焦点/光标/开关 `#417CDD`，链接浅 `#1D4ED8` / 深 `#93C5FD`；页签与新对话仍中性。仅替换键盘输入模式的焦点色，沿用上游指针模式隐藏焦点轮廓的行为。Cindy 指定的两份色表未覆盖通用成功/警告/错误 token，因此这些状态未作中性替换，继续沿用宿主语义色。皮肤没有品牌紫；产品 logo 保留。

品牌行检查记录 mark 22×22，中心 x=30 与入口图标一致，文字左缘 x=49、间距 8px，字号 15px、字重 600、字距 .02em。新增的 Mac/Windows HTML 属性模拟检查品牌尺寸、中心与左缘、间距、字重和变换；这只检查共享 CSS，不验证原生窗口拖动、红绿灯或 Windows 按钮。收起与手机截图仍属于网页响应替换预览。

线上插件清单在预览期间已独立升级，旧固定作品入口未注册时会出现既有的“缺少入口”提示，另有新的“兆华作品”入口；本单保留现场事实，不把该提示当作配色或品牌排版验收通过，也未在本单改插件安装或入口策略。之后预览接入已合入的市场行简化，保留该改动。
