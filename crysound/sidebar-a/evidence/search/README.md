# 默认柔和与搜索入口行预览

本轮在手册指定的持久浏览器中建立专用标签页，用分支文件替换品牌、侧栏、工作区和公司设置模块的响应。查询与结果来自已登录的真实服务器；没有部署镜像，没有修改会话、授权、安装记录或本人偏好。外观及视图偏好隔离在此标签页的会话存储。截图隐藏真实会话标题、摘要及账号信息，替换为示例文字。

浅色、深色各有桌面静息/展开/结果、收起图标栏、390×844 手机静息/展开/结果、对话页签、外观设置行，共十八张。收起图标栏点击搜索会展开成桌面输入行，行为见 [verification.json](verification.json)。
