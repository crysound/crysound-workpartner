# 侧栏方案 A：正式实现与交付

固定顺序为新对话 / 作品 / 自动化 / 市场（插件·技能）/ 插件入口 / 最近对话。原型保留在草稿 PR #130，仅供参考，不合入；本目录记录正式包补丁和验收。正式实现不包含原型文件。

## 行为

- 顶部搜索直接请求工作区所有者已有的搜索状态，与搜索快捷键使用同一个控制器；保留内容搜索、分页、归档结果及定位。收起状态搜索会展开侧栏；手机沿用抽屉、焦点限制和 Esc。macOS 隐藏侧栏时窗口顶部仍有搜索；Windows 收起时为搜索预留菜单空间。
- 作品的稳定面板 id 为 `baoyu-design.artifacts`，自动化为 `schedules`，市场为 `plugins`。只呈现已有注册，不伪造打不开的入口；缺少固定入口时提示去设置或市场启用。“我的工作台”仍是个人插件，不并入作品或账号菜单。
- 其他插件按显示名称的中文拼音排序，同名用所属插件标识作 Unicode 后备键；同插件多入口再按 `order`、同值注册顺序排列。归属使用现有注册账本的 `registrant`，显示名称从只读插件清单解析；无清单权限或元数据时用该插件已有入口名称。没有新增安装时间、记录格式或持久设置。0 个无占位，1–2 个直显，3 个及以上全部进入更多，菜单保留活动项和原面板打开回调。
- 工作区数量不超过一个时默认平铺（含无归属会话），多个时默认分组；工作区树偏好保留。显示选项保留手动分组、排序、归档筛选和新建；一个工作区时可从这里管理原工作区。手动选视图立即生效，数量变化后重新选择默认投影，不迁移会话归属或已存分组。
- 新对话改为普通行，保留创建权限检查。分组视图默认展示量由 5 提高到 12，保留活动会话提升、展开其余、搜索定位；平铺沿用原有完整滚动列表。桌面会话行仍为 32px，手机为 40px。账号菜单下载沿用已完成的 #131，桌面隐藏。

## 共享发布路径

`patch-sidebar.mjs <runtime node_modules>` 只接受两个包都为 `0.2.2-rc.1`；替换必须各唯一命中，否则抛错。在任何写入之前准备两个模块，重复执行字节不变；写入时断开硬链接，保留权限。可接在已有市场补丁之后，不修改其他市场行为。

网页版在 Dockerfile 安装固定 dsh 及市场修补后运行；桌面在 `prepare-dsh.ts` 物化运行时后、生成完整性记录前运行。两边消费同一份补丁和品牌 CSS。单改源 TSX 或网关无法发布本改动。

**发布依赖：必须与 #133“兆华柔和”皮肤合到同一次伙伴镜像更新，不单独换线上镜像。** 皮肤负责外观，侧栏负责结构；合并时重点核对双方的 `brand.css`、Dockerfile、桌面准备脚本以及皮肤对新对话和收起控件的选择器。皮肤偏好继续默认关。

由伙伴助理重建伙伴镜像、按既定策略更新容器；桌面随下一安装包生效。本 PR 不触发构建、不改工作流、不动线上容器。回退时使用上一镜像和上一桌面安装包；本改动没有用户数据迁移，原分组和会话不需要回填。不要直接在共享包存储或运行中容器里改文件。

## 本轮证据与复跑

轻量检查不安装依赖、不打包、不建镜像。先下载两个固定包的 npm tarball 并解压到临时 `node_modules/@deepseek-ai/dsh-client-ui-{sidebar,workspace}`，不执行安装脚本，然后运行：

```sh
SIDEBAR_RUNTIME_MODULES=/tmp/sidebar-runtime/node_modules node --test crysound/scripts/tests/sidebar.test.mjs
node --check crysound/scripts/patch-sidebar.mjs
node --check crysound/scripts/sidebar-policy.mjs
node --check crysound/scripts/tests/sidebar.browser.mjs
```

单元检查覆盖固定顺序、0/1/2/3 门槛、同插件多入口、元数据名称排序、工作区投影、真实发布模块激活、实际面板/菜单回调、创建权限、市场补丁前序、幂等、硬链接及权限、版本变化和未命中时不写入。它使用发布模块与服务替身验证组件回调，不冒充真实安装生命周期。

浏览器检查使用手册配置的持久浏览器，先开专用标签页并访问已登录的伙伴页面。`CDP_TAB` 指定该页，运行：

```sh
CDP_TAB=<专用标签页> SIDEBAR_EVIDENCE_DIR=/tmp/sidebar-evidence node crysound/scripts/tests/sidebar.browser.mjs
```

脚本只在该标签页用浏览器响应替换预览本分支的两个模块及品牌 CSS，业务接口仍来自现有真实服务器；不更改服务器或安装包，不写业务数据，不运行模型回合。截图仅截侧栏，姓名和真实会话标题用外观遮罩替换。它不是本分支完整构建的服务，也不是 Electron；因此本轮没有提供符合真实构建和模型回合条件的 GIF。

本轮结果见 [verification.json](evidence/verification.json)：真实搜索、市场打开、归档筛选入口、单工作区管理入口、展开及收起搜索、手机抽屉和 Esc 关闭通过，没有脚本异常。1440×720 视口、有一个个人插件入口时完整可见 11 条会话；这是一次页面几何采样，数量受列表可用高度及额外插件入口占用限制，不作为其他数据和窗口下的增益保证。
