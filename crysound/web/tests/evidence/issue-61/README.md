# 插件页改动预览

这些截图是合并前预览，不能代替上线验收。浏览器使用本轮手册指定的持久会话、独立标签页；页面脚本只在该标签页的响应中替换为本分支的市场标签补丁与品牌文件，没有修改线上服务、安装插件或发布数据。

索引由本分支的真实 `createMarket` 处理器读取临时测试记录、模拟注册表生成，包括公司发布账号的 design / motion 和普通同事的 colleague。生成结果注入本标签页的市场列表内存状态，由真实 `DiscoverSection` 渲染。中英文切换仅更新标签页内存，不写用户偏好。截图包含市场侧栏入口，账号与会话区域用“预览工作区”遮罩覆盖。

- [中文预览](market-zh.png)：侧栏为“市场”，右侧小号灰字“兆华 · 第三方”，位于演示文稿、视频剪辑之后；兆华市场排第一并选中；兆华设计、兆华动效显示兆华官方和作者兆华工作伙伴；团队工具显示示例同事，无官方标识。
- [英文预览](market-en.png)：侧栏为 Market / Crysound · Third-party；CRYSOUND market → Third-party market → Installed；官方标识为 CRYSOUND official，插件中文名不变。

浏览器还核对了默认选中公司市场、方向键右移会聚焦并选择第三方市场且加载其内容、主动点击已安装会显示现有插件、主动返回公司市场成功。从已安装切到演示文稿，再点侧栏市场，默认回到公司市场。临时注册语言包后，正常 locale / t 机制按语言包翻译了两个标签、侧栏名称和说明，而非固定中文或英文；语言包只存在该标签页的内存。

构建期补丁在公开的 dsh 0.2.2-rc.1 插件管理客户端上实际运行，通过 `node --check`。轻量回归命令：`MARKET_UI_CLIENT=<公开包的 lib/client.js 路径> node --test crysound/scripts/tests/market-runtime.test.mjs`（Node 24，需要已有的 tsx 依赖）。三个测试执行真实桌面完整性验证：先修补后记录校验通过；重复修补字节不变且校验仍通过；先记录校验再修补会被拒绝；未知运行时结构明确报错。桌面准备流程在生成描述文件、签名与原有冒烟验证前调用该修补函数。

待伙伴助理完成：构建镜像、在部署配置中指定官方发布账号与包范围、重建网关并发布公司配置、空闲升级用户容器、刷新真实索引，核对两个真实官方包和普通同事包；桌面版随下个安装包检查。此轮未执行构建、合入、部署或生产安装验收。
