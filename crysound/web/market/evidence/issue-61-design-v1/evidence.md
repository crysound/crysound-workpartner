# 设计 1.0.0 差异验收

2026-11-07 北京时间，按伙伴助理对 #61 的答复，将设计验收目标更新为已批准的 `@crysound/design@1.0.0`。0.2.1 从未发布到公司市场，已被新版替代。动效保持 0.1.3，此前动效、附件及其余路径的通过记录继续有效，不重复执行。

本轮沿用已配置的持久浏览器和独立标签页，实际运行分支修补后的 dsh 0.2.2-rc.1 与生产市场处理器。设计与作品底座取各自已合入 PR 的原始文件，不修改包内技能或引导，不替换浏览器脚本响应、远端服务或会话。隔离注册表的批准记录仍为合成数据；真实批准依据是伙伴助理答复，并独立读取登录后的线上引导核对版本和完整元数据。

| 项目 | 实测结果 |
| --- | --- |
| 线上引导 | 登录后的 `guides.json` 返回设计 1.0.0、显示名“兆华设计”，中英文说明、引导词及三个示例逐字匹配已合入包 |
| 完整原生网页启动 | 首页、两种语言示例发送均先完整刷新；没有“Failed to load plugins”，当前页面控制台无错误，无响应替换 |
| 首页与市场 | 两种语言分别走首页入口及市场“使用”，共四条路径；说明、三示例和能力标签匹配包内元数据，市场卡片显示 1.0.0 |
| 三个示例 | 中文为声学相机海报、桌面与手机双画板、修改已有画布文案；英文逐项对应，不再使用旧版聚合插件示例 |

| 自动安装依赖 | 在全新隔离目录仅指定 `@crysound/design@1.0.0`，经生产市场处理器执行包管理器安装，实际下载并安装 `@crysound/artifacts@1.0.0`；直接依赖只列设计，底座由 `^1.0.0` 自动解析。两包全部发布文件与合入源码逐字节一致 |
