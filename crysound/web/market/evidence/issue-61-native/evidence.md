2026-11-07 北京时间，本轮沿用配置的持久浏览器独立标签页，进入负责人提供的隔离 dsh 0.2.2-rc.1 网页。运行当前分支修补过的发布模块和生产市场处理器，没有替换浏览器脚本响应，也没有远端插件清单、输入框或会话替身。没有读取正式用户数据、修改线上插件、提交模型请求或重启线上容器。

**这轮使用合成包说明和审批数据，不是获批正式包验收。** 本机只有分支中的 design 0.1.0、motion 0.1.2；在各自隔离副本中增加 `crysound/tests/fixtures/guide-packages.json` 的说明内容，保留原版本。测试注册表将这两个副本视为批准，生产市场处理器根据包内元数据生成引导和索引。没有把它们改成 design 0.2.1 或 motion 0.1.3。

复查脚本通过 CDP 操作真实按钮和原生键盘输入，并按可见状态等待。截图只截工作区输入区域或测试卡片，记录不含登录地址和令牌。机器结果保存在 `flow.json`。

最初市场显示 Install 的原因是隔离测试入口只在 profile 中启用 bundles，没有把本地包登记到 dependencies。原生市场以 dependencies 判断是否安装；修正隔离入口的本地登记后显示 Use。产品代码无需为此修改，也没有安装依赖。

原生命令取消会保留分隔空格，复查脚本在下一轮选择前显式清空输入；有文字的草稿保留已另行核实。这轮仅验证英文说明显示，没有验收语言切换。复查工具及测试入口由负责人维护在本机运行资料中。
