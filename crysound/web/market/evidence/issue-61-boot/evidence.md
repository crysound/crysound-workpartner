# 原生网页启动回归

2026-11-07 北京时间，在既有持久浏览器的独立标签页测试 dsh 0.2.2-rc.1。沿用登录，只替换该标签页收到的三个运行时模块响应后完整刷新；没有组件预览、假会话或远端接口替身。没有改线上容器、安装插件或发送模型请求。

`verify-guide-boot.mjs` 先去掉补丁的 `remote` 声明，重现原生 “Failed to load plugins”，捕获具体异常 `cannot get property "remote" without inject`。随后恢复修复再次完整刷新，原生输入框与首页动效入口出现，当前页面控制台无错误。阴性对照和成功页面分别见 `before.png`、`after.png`；成功截图裁去侧栏及账号区域。机器记录见 `boot.json`，其中运行时网址已移除。

根因是 Cordis 将 `remote` 和 `remote.pluginManager` 作为独立注入项检查。补丁 v1 在激活时订阅 `ctx.remote.$on`，却只声明了子命名空间。继续核对还发现远端清单是 `{ ok, value }` 而非数组，会话 scope 需要 `get("conversation")`，以及原生首页原本不渲染 composer dock。这些路径均已修正，v1 可升级为 v2，第二次执行保持字节不变。
