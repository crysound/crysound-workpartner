# 网页搜索与抓取

本目录在网页镜像构建时适配 `@deepseek-ai/dsh-{web-search-deepseek,web-fetch-http,tool-web}@0.2.2-rc.1` 的发布产物，不更改上游包源码、不安装新依赖。`patch.mjs` 校验版本、唯一替换位置和重复执行；不匹配时构建失败。运行时代码随镜像固定，不属于挂载的公司配置。本次不改变桌面安装包。

搜索通过现有公司地址和凭据走 Messages 接口，读取发起工具调用的 Agent 的 `model.current().model`。会话模型为 `codex/*` 时先用 `codex/gpt-6.1-sol`，其他模型先用 `deepseek/deepseek-flash`，拿不到会话模型时先用 GPT。HTTP、网络、解析或缺少原生搜索结果块等请求失败，均以另一模型再尝试一次。每次最多 30 秒，工具默认总时限为 65 秒；个人明确设置的工具时限仍优先，设得更短可能来不及回退。本人取消、缺凭据或请求日志写入失败不重试。每次实际尝试沿用上游请求日志和结构化结果映射。

抓取先匿名 GET，使用常见桌面浏览器的 User-Agent 和 `Accept-Language: zh-CN,zh;q=0.9,en;q=0.8`。允许 HTTP→HTTPS、主域→www 等跨源跳转，最多五跳。每次请求都检查协议、URL 身份信息、长度、所有 DNS 答案和 IP 地址，再把已检查的地址固定到连接；IPv4 私网、本机、链路本地、保留段、IPv6 非公网单播和过渡地址均拒绝。不使用系统代理，不携带 Cookie 或授权头。原发布产物实际允许私网地址，本改动新增公司限制；读取容器服务应使用本机工具及现有服务预览入口。

成功且未截断的 HTML 去掉脚本、样式后的文字不足 240 字，并含脚本或需要 JavaScript 的提示时，复用 `SLIDESTUDIO_PLAYWRIGHT_RUNTIME` 指定的镜像现有 Chromium。每个用户容器同一时间只渲染一个页面，忙时明确报错；单次渲染最多 15 秒，且仍受原抓取总时限限制。使用全新匿名上下文，禁止服务工作线程、WebSocket、下载、非 GET 请求，以及图片、字体和媒体请求。页面、脚本与其他资源均通过同一地址检查和连接固定；在 Node 中逐跳跟随跳转并返回最终资源，浏览器不自行沿 HTTP 跳转联网。主文档注入最终地址作为 base，并报告最终地址。单资源沿用 `maxResponseBytes`，整页最多该值的四倍、64 个资源、8 个并行请求；输出沿用 `maxBodyChars`。退出会中止网络请求并关闭浏览器。

登录路径、登录标题或密码输入框均返回“需要登录，无法抓取”；JS 导航到登录页同样处理。登录、验证码、必须 Cookie 或非 GET 接口、长期网络活动等站点仍可能无法读取；渲染失败会明确报错，不把空壳当作成功正文。重定向后的脚本仍按请求时地址解释模块相对导入，这类站点需上线实测。渲染后继续用上游 HTML 正文抽取，不执行站点提供的命令。

## 轻量检查

使用 Node 24 和已有的固定版本运行时依赖目录，不在本机安装依赖或建镜像：

```sh
DSH_WEB_TOOLS_RELEASE_ROOT='<dsh 的 node_modules>' \
PARTNER_TEST_PLAYWRIGHT='<已有 playwright/index.mjs 的绝对路径>' \
PARTNER_TEST_CHROMIUM='<已有 Chromium 可执行文件的绝对路径>' \
node --experimental-vm-modules --test crysound/web/web-tools/web-tools.test.mjs
```

测试把发布产物复制到独立临时目录再修补，不改变指定的运行时。宿主服务及 schema 使用局部替身；实际执行发布 JS 的模型选择、搜索 HTTP 映射、请求日志、工具时限注册、抓取读取与字节上限。网络用随机端口的本机服务器，只有测试传输把已检查的公网地址映射到测试服务器。Chromium 用真实浏览器执行 JS、拦截私网子请求和主导航、识别登录导航、验证渲染并发限制与浏览器关闭。不设置 Playwright 路径时只跳过浏览器项，不能视作浏览器验收通过。所有测试只使用假凭据。

## 部署、验收与回退

伙伴助理保留旧镜像标签后重建网页镜像，先只给长期测试账号换镜像。先在 GPT 和其他模型会话分别搜索同一查询，从请求日志核对首选模型；分别让首选返回 HTTP 错误、超时和无原生结果块，核对仅回退一次及引用来源。双失败要明确报错，本人取消应停止。

测试账号还需实测至少五个国内站，建议含公司官网、百度、网易、政府网站和一个已确认需要 JS 的公开页面；记录原始地址、每跳地址、HTTP 状态、抓到的标题/正文片段、是否实际调用渲染和结果。至少有一个真实 HTTP→HTTPS 跳转和一个实际触发渲染的页面，若建议站点未覆盖则补充替换。再核对知乎等登录站明确报错、重定向到本机或云元数据被拦截。公开站探测、本地夹具和模拟模型返回不代替测试账号经公司模型网关的验收。本 PR 尚未在测试账号完成这些项目。

测试通过后按现有空闲升级流程逐人换镜像。无需更改公司配置、网关、用户数据或密钥。回退时按空闲升级流程把容器恢复到保留的旧镜像；此次只改镜像内代码，不需要回滚个人配置或用户数据。旧镜像的搜索和抓取限制随之恢复。
