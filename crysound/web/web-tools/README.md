# 网页搜索与抓取

本目录在网页镜像构建时适配 `@deepseek-ai/dsh-{web-search-deepseek,web-fetch-http,tool-web}@0.2.2-rc.1` 的发布产物，不更改上游包源码、不安装新依赖。`patch.mjs` 校验版本、唯一替换位置和重复执行；不匹配时构建失败。运行时代码随镜像固定，不属于挂载的公司配置。本次不改变桌面安装包。支持远端公司配置的桌面版会刷新搜索模型和工具时限，但不含本目录的正文映射与回退适配。

网页搜索优先走 DeepSeek Search API（`/_zp/ds-tools/search`），不调用摘要模型；网关路径与容器身份沿用 #182 的 `CRYSOUND_DS_TOOLS_BASE`、`CRYSOUND_DS_TOOLS_TOKEN_FILE`。只允许固定内部网关地址，身份令牌不能发给外部服务；付费钥匙只在网关中。每个查询按 Unicode 字符截到 128 字符，`count: 10`，多个查询沿用发布工具的并发派发与去重合并。来源保留标题、URL、日期和该条的 `summary`，摘要合并空白并截到 800 字符，不拆开代理对。顶层 `content` 留空：API 没有跨来源综合回答，不能把某一条摘要冒充综合正文。Flash/Luna 回退仍保留最后一次原生搜索后的正文、引用片段和原来的 800 字符上限；有正文但无来源仍可返回，不能冒充满足来源数量。

回退顺序是 Search API → `deepseek/deepseek-flash` → `codex/gpt-6-luna`，不依赖会话模型。总截止时间从搜索入口开始计 18 秒；API 最多 4 秒，Flash 最多 12 秒且从剩余时间中预留至多 6 秒给 Luna（余量不足 12 秒时各分一半），Luna 使用全部剩余时间。API 用满 4 秒时，Flash 约 8 秒、Luna 约 6 秒；API 或 Flash 很快失败时，后级获得尚未花掉的时间。凭据读取、HTTP 和响应解析均计入时限，超时后的身份读取不能补发请求。本人取消不回退；模型凭据或请求日志在 HTTP 前失败不回退。

没有内部网关配置时直接从 Flash 开始；网关开关关闭或缺付费钥匙时由网关立即返回不可用，不发付费请求，搜索随即从 Flash 开始。HTTP、网络、空结果或不可解析响应均可回退。开关和钥匙状态由网关持有，不复制到用户容器；本单不改网关、模型网关、上游源码或共享公司模型配置。Flash/Luna 沿用发布运行时的凭据和请求日志。每级耗时、预算、成功/失败/超时和胜出结果通过默认关闭的计时入口记录，不记录查询、正文、地址或凭据。

搜索和抓取工具的说明继续要求：正文或来源摘要足以回答时，直接引用已有链接作答，不为确认同一来源再次抓取；需要原文、细节、表格或补足指定来源数时仍可抓取。这是模型行为引导，不能保证每轮一定不抓取。API 对接、自查范围及伙伴助理的部署验收清单见[交付记录](../../config/evidence/issue-186/README.md)。

### 请求前空档

默认关闭的分段诊断、开关、JSONL 字段与离线分析命令见[联网工具分段计时](TIMING.md)。它只在显式开启的测试进程中给固定发布产物插桩，不改变工具调度顺序；尚需伙伴助理在新镜像中完成三次天气查询验收。

本地固定版产物检查显示，工具执行到搜索 HTTP 派发之间只等待凭据读取，随后同步记录请求并派发；本地凭据实现从内存、继承环境与启动环境读取，没有网络请求或固定等待。回归测试冻结 JavaScript 定时器，不推进时钟即可经真实修补产物完成凭据读取、请求记录和 HTTP 派发，说明本调用段没有定时等待或额外模型轮次；这项测试不是线上提速测量。

上游 `packages/core/agent-loop/src/agent.ts` 先读完模型流，再记录 assistant message 并执行工具，因此“页面已经显示工具调用”到“搜索 HTTP 请求记录”包含模型流尾部和工具策略阶段。没有本单原始线上流帧与执行阶段时间戳，不能断定 2.7–4.6 秒具体落在哪一段，也不宣称已经消除该空档。本单按要求只改公司层；上线验收需分别取工具调用首次帧、模型流结束、`tool/call` 与 `web/deepseek-search-llm-request` 的时间，区分流尾部、工具调度/审查和凭据阶段，后续再决定是否需要改上游。

抓取先匿名 GET，使用常见桌面浏览器的 User-Agent 和 `Accept-Language: zh-CN,zh;q=0.9,en;q=0.8`。允许 HTTP→HTTPS、主域→www 等跨源跳转，最多五跳。每次请求都检查协议、URL 身份信息、长度、所有 DNS 答案和 IP 地址，再把已检查的地址固定到连接；IPv4 私网、本机、链路本地、保留段、IPv6 非公网单播和过渡地址均拒绝。不使用系统代理，不携带 Cookie 或授权头。HTTPS 握手通过 ALPN 声明 HTTP/1.1，避免百度等站点在未协商协议时直接断开连接。即使服务器忽略 identity 偏好仍返回压缩内容，也流式解码 gzip、deflate、br（至多两层，按逆序解码）；压缩传输和解码后正文均受 `maxResponseBytes` 限制，取消或解码错误会关闭整条传输。未知压缩格式明确报错。主文档无论是否声明超限的 Content-Length，都按字节上限读取前段并关闭剩余传输，返回截断标记；压缩传输上限仍明确报错，渲染子资源仍使用原有严格大小限制。原发布产物实际允许私网地址，本改动新增公司限制；读取容器服务应使用本机工具及现有服务预览入口。

主文档先在字节上限内解码，识别登录和动态页面后，去掉注释、脚本、样式、noscript 和隐藏 textarea 再应用 `maxBodyChars`；标题、正文、链接和可见 textarea 保留。这样页面头部样式或隐藏的样式缓存不会占满正文额度。真实字节或正文字符截断继续由原工具输出截断提示。

成功且未截断的 HTML 去掉脚本、样式后的文字不足 240 字、article/main 容器也没有至少 80 字正文，并含脚本或需要 JavaScript 的提示时，复用 `SLIDESTUDIO_PLAYWRIGHT_RUNTIME` 指定的镜像现有 Chromium。`web-fetch-http` 插件配置增加 `renderConcurrency`（默认 1）和 `renderTimeoutMs`（默认 2000）；两者必须是正整数，时限不能超过 Node 定时器范围，非法值在注册前报错。同一时间只接受配置数量以内的渲染，忙时明确报错；渲染还受原抓取总时限限制。操作人员可在个人 profile 的对应条目中配置，例如 `config: {renderConcurrency: 2, renderTimeoutMs: 20000}`，同时保留该条目的其他已有配置。使用全新匿名上下文，禁止服务工作线程、WebSocket、下载、非 GET 请求，以及图片、字体和媒体请求。页面、脚本与其他资源均通过同一地址检查和连接固定；在 Node 中逐跳跟随跳转并返回最终资源，浏览器不自行沿 HTTP 跳转联网。主文档注入最终地址作为 base，并报告最终地址。单资源沿用 `maxResponseBytes`，整页最多该值的四倍、64 个资源、8 个并行请求；输出沿用 `maxBodyChars`。退出会中止网络请求并关闭浏览器。

登录路径、登录标题或密码输入框均返回“需要登录，无法抓取”；JS 导航到登录页同样处理。登录、验证码、必须 Cookie 或非 GET 接口、正文无法在时限内生成等站点仍可能无法读取；渲染失败会明确报错，不把空壳当作成功正文。重定向后的脚本仍按请求时地址解释模块相对导入，这类站点需上线实测。渲染后继续用上游 HTML 正文抽取，不执行站点提供的命令。

## 按问题摘要

`web_fetch` 增加可选字符串 `prompt`，研究时填要找的问题或证据。成功抓取后先按原工具上限转换正文为 Markdown；不超过 `fetchSummaryMinChars`（默认 12000 字符，含来源与截断提示）的短正文直接返回，较长正文才通过公司网关的 Messages 接口做一次摘要，不再搜索。辅助模型按问题保留原文关键句、数字、单位、日期和限制条件；原始 URL 和重定向后的 URL 由代码附上，不依赖模型引用。主模型只收到摘要；原文截断标记保留。摘要连同来源与提示一起受 `fetchMaxOutputChars` 总字符上限约束，不再额外裁剪摘要；超限由原工具渲染器截断并标记。

公司 `tool-web` 配置字段如下；`profile-upgrades.mjs` 每次启动刷新新老 profile，保留其他个人工具选项：

| 字段 | 公司默认值 | 用途 |
| --- | --- | --- |
| `fetchSummary` | `true` | 摘要开关，关闭后返回原抓取输出；DeepSeek 与 Treg 兜底由独立开关控制 |
| `fetchSummaryModel` | `deepseek/deepseek-flash` | 摘要模型，可改为公司网关提供的 GPT 快速档 |
| `fetchSummaryBaseURL` | 启动环境中的公司模型地址 | 与原搜索相同的网关，发送到 `/messages`；配置不写部署地址 |
| `fetchSummaryTimeoutMs` | `2000` | 包含凭据读取、请求和响应解析的额外等待上限 |
| `fetchSummaryMaxTokens` | `1600` | 摘要输出预算；普通摘要关闭思考、不附带搜索工具 |
| `fetchSummaryMinChars` | `12000` | 有界 Markdown 不超过此长度时直接返回 |
| `fetchDeepSeek` | `true` | 失败时与 Treg 并发请求 |
| `fetchDeepSeekTimeoutMs` | `8000` | 付费抓取阶段上限，仍受剩余总预算限制 |
| `fetchDeepSeekMinChars` | `80` | 返回正文去空白后的最小字符数；两路共用的最小正文长度 |
| `fetchTreg` | `true` | 失败时与 DeepSeek 并发请求 Crawl4AI |
| `fetchDirectTimeoutMs` | `1500` | 开启任一兜底时的直抓上限，包含浏览器及清理 |
| `fetchTregTimeoutMs` | `8000` | Crawl4AI 上限，包含公开地址检查、身份读取、请求和解析，并受剩余总预算限制 |
| `fetchTotalTimeoutMs` | `9500` | 直抓、两路并发抓取和摘要共用总工作预算，外层另留 500 毫秒 |

沿用搜索的 `DEEPSEEK_API_KEY` 凭据服务（无凭据服务时才读启动环境），不增加密钥或服务。已有主模型请求的日志机制不改；辅助请求使用发布运行时的 `appendPluginRecord` 保存为可忽略的 `plugin:crysound/web-summary-request` 记录，包含实际地址和不带密钥的请求体。辅助调用会增加一次现有模型服务用量，整体成本和性能须上线测量。公司补丁文件在镜像中解析已安装的凭据、启动环境和会话依赖，轻量检查包含真实导入和会话重放。

没有 `prompt`、空问题、开关关闭、HTTP 错误页或空正文不调用辅助模型。凭据不可用、日志不能保存、请求失败、响应不可解析或没有摘要、超过摘要时限，都保持原结果，由原渲染器返回截断原文。本人取消则抛出取消，不能继续交回正文；超时后才完成的凭据读取也不能补发请求。不重试辅助调用，不跟随模型接口重定向。开启任一兜底时，工具时限为 `fetchTotalTimeoutMs` 再留 500 毫秒结果处理余量（默认 10 秒）；直抓失败后两路并发、不重试，摘要也不能超出剩余预算。关闭 `fetchDeepSeek` 和 `fetchTreg` 两个兜底时，恢复原抓取时限加摘要上限；同时关闭摘要即恢复原抓取时限。公司联网提示同时要求网页遇到 403、登录或反爬时更换来源，禁止写脚本或 curl 命令绕过。

## 失败页面与慢页面的并发兜底

普通页面继续匿名直抓。直抓失败、HTTP 错误、空正文或超过 `fetchDirectTimeoutMs` 时，同时尝试 DeepSeek Fetch 和 Treg 的 `treg.web.extract`；第一份达到最小正文长度的结果胜出，取消另一条请求，两路都失败则保留原错误/HTTP 结果。返回的 Markdown 沿用短正文直返、长正文按问题摘要和原 URL 引用。不再使用 Codex 打开网页，搜索退路不变。私网、含身份的 URL、安全拦截及本人取消不通过兜底绕过。

两路仅将现有容器身份令牌发送给固定内部主机。入口脚本设置 `CRYSOUND_DS_TOOLS_BASE` 和 `CRYSOUND_TREG_BASE`，分别指向内部 3091 端口的 `/_zp/ds-tools/` 与 `/_zp/treg/`；令牌读取 `CRYSOUND_DS_TOOLS_TOKEN_FILE`，默认 `/data/.zp-market-token`。不把公司付费钥匙放进用户容器。

Treg 仅额外放行 `treg.web.extract`，网关强制 `X-Treg-Route-Prefer: crawl4ai`、`X-Treg-Route-Waterfall: 0`、`X-Treg-Route-Max-Cost: 0.005`（个人单次上限更低时取更低值）。不透传调用者的路由或归属头，沿用本人日/月额度与预算配置；额度用完时本路失败，不影响 DeepSeek。正文按公开目录规定读取 `output.pages[0].markdown`；空 pages、薄正文或无效结构不能胜出。取消传到上游，不自动重试未知结果；取消不保证提供方免计费。

DeepSeek 仅在内部端口接受精确 POST `/_zp/ds-tools/fetch` 与 `/search`；公网拒绝，签名身份、有效期和当前开通名单必查。Fetch 使用[官方协议](https://api-docs.deepseek.com/api/fetch/)，search 转发已备好，尚未接入搜索流程。网关读取 `DEEPSEEK_TOOLS_KEY_FILE`（默认 `/run/deepseek-tools/deepseek-tools.key`），也支持手工部署时的 `DEEPSEEK_TOOLS_API_KEY`。文件缺失时不影响启动，请求视为不可用；`DEEPSEEK_TOOLS_ENABLED=0` 直接阻止上游调用，不作废与模型网关共用的钥匙。请求最多 16 KiB、响应最多 2 MB，不跟随重定向、不透传用户 Cookie 或上游错误原文。

`DEEPSEEK_TOOLS_USER_RPM` 默认 20，跨重启按人限流。`DEEPSEEK_TOOLS_MONTHLY_USD` 默认公司每北京自然月 10 美元、只可调低，每成功请求 750 微美元。在单网关进程独占的 `/state/ds-tools.json` 中原子同步预留；明确上游失败释放，断连/取消/崩溃等未知结果保留，成功但解析失败也占额。月界新请求记新月，在途请求仍记原月。账本 `days[北京日期][本人标识][fetch或search]` 持久保存实际派发数 `calls` 和上游成功数 `success`，不含钥匙、URL 或正文；损坏账本拒绝启动，不清空重置。

默认直抓 1.5 秒，为两路各最多 8 秒留下完整窗口；总工作预算 9.5 秒，外层工具留到 10 秒。选择 1.5 秒是为了覆盖需求单中 DeepSeek 7.9 秒的慢页，属于待线上验证的预算取舍；原来可在 1.5–2.6 秒直抓的页面可能因此走付费兜底。摘要也只用剩余预算，临近截止保留正文。夹具验证时限与取消，不能证明真实救回率或速度。

浏览器仍只处理 JS 空壳，article/main 已有至少 80 字正文不启动浏览器；导航等待 DOM 和可见正文，不等网络空闲，默认渲染最多 2 秒并受直抓预算约束。退出会中止资源请求、关闭浏览器并释放渲染槽。

## 轻量检查

使用 Node 24 和已有的固定版本运行时依赖目录，不在本机安装依赖或建镜像：

```sh
DSH_WEB_TOOLS_RELEASE_ROOT='<dsh 的 node_modules>' \
PARTNER_TEST_PLAYWRIGHT='<已有 playwright/index.mjs 的绝对路径>' \
PARTNER_TEST_CHROMIUM='<已有 Chromium 可执行文件的绝对路径>' \
node --experimental-vm-modules --test crysound/web/web-tools/web-tools.test.mjs
```

测试把发布产物复制到独立临时目录再修补，不改变指定的运行时。宿主服务及 schema 使用局部替身；实际执行发布 JS 的模型选择、搜索 HTTP 映射、请求日志、工具时限注册、抓取读取与字节上限。网络用随机端口的本机服务器，只有测试传输把已检查的公网地址映射到测试服务器。压缩用例覆盖 gzip、deflate、br、两层编码、未知编码及压缩/解压大小上限；大页面用例覆盖超长头部及隐藏样式缓存、可见 textarea、声明长度超限、分块传输、压缩正文、字节边界和提前关闭连接；发布插件的配置默认值、覆盖和非法值会通过实际注册入口验证。Chromium 用真实浏览器执行 JS、拦截私网子请求和主导航、识别登录导航、验证渲染并发限制与浏览器关闭。不设置 Playwright 路径时只跳过浏览器项，不能视作浏览器验收通过。所有测试只使用假凭据。摘要用例执行已修补的实际工具注册和调用、真实 Markdown 转换；覆盖问题/无问题、短正文跳过、开关、公司地址/模型/预算、HTTP/网络/响应/凭据/日志错误、2 秒摘要超时、本人的取消、超时后的凭据回调、原文与输出截断、真实依赖导入及辅助请求记录重放。

额外设置 `PARTNER_TEST_LIVE_FETCH=1` 时，用真实公网传输抓百度首页，断言返回标题及正文，覆盖 HTTPS 协议协商；默认跳过该项，避免离线测试依赖外网。此项不使用登录浏览器，不等同于部署后通过测试账号的整体验收。

## 部署、验收与回退

伙伴助理保留旧镜像标签后重建网页镜像，先只给长期测试账号换镜像。同步公司配置 `crysound/config/partner.patch.yml`，先在 GPT、Claude 和 DeepSeek 模型会话分别搜索同一查询，核对 Search API 首选、Flash 和 Luna 回退；分别模拟 API 错误或超时、Flash 错误，核对剩余时间分配和引用来源。网关关闭或缺钥匙应直接转 Flash；所有服务失败要明确报错，本人取消应停止。Flash/Luna 有正文但无链接时仍直接返回正文。

测试账号还需实测至少五个国内站，建议含公司官网、百度、网易、政府网站和一个已确认需要 JS 的公开页面；记录原始地址、每跳地址、HTTP 状态、抓到的标题/正文片段、是否实际调用渲染和结果。至少有一个真实 HTTP→HTTPS 跳转和一个实际触发渲染的页面，若建议站点未覆盖则补充替换。再核对知乎等登录站明确报错、重定向到本机或云元数据被拦截。公开站探测、本地夹具和模拟模型返回不代替测试账号经公司模型网关的验收。本 PR 尚未在测试账号完成这些项目。

搜索提速还需同步共享公司配置，包含工具总时限、抓取输出上限和停止条件；部署、同题性能验收与字段级回退见[公司配置说明](../README.md#联网搜索提速)。测试通过后按现有空闲升级流程逐人换镜像；Search API 依赖 #182 网关接口先上线，不增加或轮换密钥。


摘要部署需同步同一提交的 `partner.patch.yml`、`profile-upgrades.mjs`，并重建网页镜像。先升级长期测试账号；新会话用 `web_fetch({url, prompt})` 核对实际辅助模型、原 URL、关键原句和数字，故障时核对原文回退。随后复跑 #137 原来的同一组 3 题，固定模型、推理档位、预设、插件和新会话，每题改前改后各三次并交替执行。分别记录上下文峰值、主模型生成时间、总耗时、辅助摘要耗时/失败次数，以及答案中不少于 5 个去重来源；按原口径比较，保留完整会话，不用合成返回宣称实际提速。此处的无密钥测试不代替新镜像、真实模型摘要质量或三题性能验收，这些由伙伴助理上线后完成。

只回退摘要时，在共享公司配置中设 `fetchSummary: false`，安排测试账号重启并从新会话核实不再产生摘要请求；确认后按既有空闲升级策略逐人重启。不用重建镜像、不换密钥，原文仍按 40000 字符上限返回。要回退整个运行时则换回保留的旧镜像。桌面安装包不含本次摘要和并发抓取补丁，继续原抓取行为；共享的换来源提示仍会更新。


本次抓取提速需要重建网页镜像，同步共享的 `partner.patch.yml` 与 `profile-upgrades.mjs`，并更新网关模块和 Compose 后重建网关。只同步公司配置不能增加兜底能力。管理员须先把已有付费钥匙准备在 `PARTNER_SECURE/deepseek-tools.key`；Compose 将网关已有安全目录额外挂到只读的 `/run/deepseek-tools`，钥匙文件缺失也不阻止网关启动，只关闭这项功能。钥匙不进镜像或用户容器，不需要新建或轮换。沿用原用户容器升级策略，先测试账号后推广。

完整本地证据和上线步骤见 [#182 验收说明](../../config/evidence/issue-182/README.md)。失败页至少救回 7/8、长尾不超过 10 秒，以及原三题性能目标，均待伙伴助理在真实部署验收。`fetchDeepSeek:false` 停 DeepSeek，`fetchTreg:false` 停 Treg；两个都关恢复原直抓时限。`DEEPSEEK_TOOLS_ENABLED=0` 在网关停 DeepSeek 上游调用，保留共用钥匙及账本。

公司镜像适配层的固定工具输出与会话重放检查：

```sh
DSH_WEB_TOOLS_RELEASE_ROOT="$RELEASE_ROOT" \
DSH_SESSION_RELEASE_ROOT="$SESSION_RELEASE_ROOT" \
node --experimental-vm-modules --test crysound/web/web-tools/exa-transcript.test.mjs
```

`SESSION_RELEASE_ROOT` 指向已有 `@deepseek-ai/dsh-session@0.2.2-rc.1` 的 node_modules；与网页工具在同一依赖树时可省略。三个固定记录覆盖 Exa 来源补充、额度不足回退和中文路径，保存完整模型可见文字、来源与日期元数据、截断标记及原始调用参数。测试执行修补后的发布工具，和只读预期记录逐项比较，再写入独立临时文件并通过真实 Session 重放，核对模型消息及搜索卡片。它是适配层的库级回归检查，不启动 dsh 进程，也不替代上游进程级 snapshot 通道或线上搜索验收。
