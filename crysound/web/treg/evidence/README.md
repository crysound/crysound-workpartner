# 数据专栏界面送审

这两张是 2026-11-07 的界面预览，不是服务上线或付费验收证明。

- [宽屏预览](data-desktop.png)：浏览器宽 1440，数据区三列。
- [窄屏预览](data-narrow.png)：浏览器宽 820，卡片随内容区自动换行。

使用本轮实际连通的持久浏览器自有标签页。截取真实发布运行时的插件管理器模块，在当前标签页应用本 PR 数据补丁与市场基础 #61 / PR #64 的现有补丁（分支头 b67737fe1e3178c67a853dd965f381ad5b3a7956），无安装依赖或重新打包。平台和价格来自本轮公开 `/catalog/platforms` 响应；安装索引和已安装状态是测试夹具，截图模拟“兆华数据已启用”。预览说明直接标在图中；裁掉了个人侧栏与账号信息。

`browser-preview.mjs` 自动核对七组中文顺序和美元价格、未安装时的确切版本与注册表、停用时的插件详情入口、已启用时传给原生新会话 API 的草稿和保留策略、目录失败及重试恢复，以及宽窄布局不横向溢出。安装、打开插件和新会话调用在当前标签页只记录参数，未实际安装插件、修改用户配置、创建会话、发送消息或付费调用。预览结束会关闭拦截并恢复视口，标签页另行关闭。

复现时先按本环境配置的浏览器入口创建自有标签页、打开已登录的工作伙伴，下载公共平台目录到临时文件，导出 #61 的 `patch-market-ui.mjs` 及它引用的 `market-locales.mjs` 并保持相对目录结构，然后：

```sh
NO_PROXY=127.0.0.1 node crysound/web/treg/browser-preview.mjs \
  <自有标签编号> <公共平台目录.json> <临时截图目录> <市场基础补丁.mjs>
```

#61 合入且实际运行时已含其补丁后，可省略最后一个参数。脚本不应接入他人的标签页。

网关另以真实 HTTP 和临时账本运行 19 项轻量测试通过，所有上游计费与管理员通知都注入假值。公司部署文件用假 .env 展开通过。实际发布客户端补丁还检查了重复运行、与 #61 的两种顺序、入口变化时失败、pnpm 硬链接不波及其他安装，以及语法。

真实公共目录只读核对通过：110 个开放平台、单个数据详情与搜索结果通过同一网关目录规则。没有使用公司令牌。

尚未验收：组织令牌费用归属、便宜接口实扣、上游日预算、真实飞书额度通知、真正的插件安装与草稿显示、最终上线整页、Electron 协议和桌面构建。桌面 TypeScript 只用 Node 24 去类型转换后检查语法；未做类型检查或打包。按任务限制未安装依赖、未跑整套测试、未建镜像；环境没有 pnpm，未完成仓库 doc-sync。
