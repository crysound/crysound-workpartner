# Search API 优先与剩余时间回退（#186）

网页搜索优先经 #182 的内部网关调用 DeepSeek Search API，不经过模型。每个查询独立请求，按 Unicode 字符截到 128 字符、`count: 10`；多查询沿用真实发布工具的并发派发、去重合并与总来源上限。API 来源映射标题、URL、日期和该来源的 summary（沿用 800 字符上限），顶层 content 留空，避免把某条来源摘要冒充跨来源综合正文。Flash/Luna 的正文和来源映射保持原行为。

所有级别共享从搜索入口开始的 18 秒截止时间，包含身份读取、HTTP 和响应解析。API 最多 4 秒；Flash 最多 12 秒，并在剩余时间中给 Luna 预留至多 6 秒（余量不足 12 秒时各分一半）；Luna 使用全部剩余时间。API 用满 4 秒后约分配 Flash 8 秒、Luna 6 秒；前级早失败时，后级能取得未花掉的时间。本人取消不回退，模型凭据或请求日志在请求前失败仍不重试。

内部网关未配置时直接从 Flash 开始。开关关闭或钥匙缺失由 #182 网关立即回答不可用，不向付费上游发请求，搜索随即转 Flash；不把网关钥匙或开关状态复制进用户容器。本单仅消费网关接口，不改网关、权限、密钥、模型网关、上游源码或共享公司配置。API 失败、空结果或无效响应依次回退 Flash、Luna。身份读取晚于截止时间时不能补发付费请求。

计时仍默认关闭。开启后追加每级 start/end、provider、分配预算、耗时、状态和胜出标记，报告增加 searchPhases；API 首次派发计入 executeToFirstSearch，不要求有模型请求记录。计时日志不包含查询、来源、正文、令牌或请求体。

## 搜索预算配置与评审修复

搜索提供方 `web-search-deepseek` 新增四个可在 `cordis.yml` 调整的字段：`searchTotalTimeoutMs`（18000）、`searchApiTimeoutMs`（4000）、`searchFlashTimeoutMs`（12000）、`searchLunaReserveMs`（6000）。取值与组合约束见[网页工具说明](../../../web/web-tools/README.md)。加载前验证，下一次搜索重新读取动态值；传给搜索辅助函数的是已解析预算。`tool-web.searchTimeoutMs` 是独立的外层工具时限，改变总时限时应同步设置。英文补充来源保留最多 5 秒的上限，总时限更短时随之缩短。

真实发布入口测试确认默认值、全部字段的非整数/非正数/非数字/超定时器范围拒绝，以及 API/Flash 大于总时限、预留不小于总时限的组合拒绝。自定义配置实际产生 1000/5000/3000 毫秒分配，设置刷新后变为 500/4000/2500；非法刷新在新请求派发前报错。另有 1 秒总时限限制英文补充停滞的用例。旧 Search API 修补产物升级后与全新修补字节相同，无重复导入；重复执行保持不变。

当前四组定向测试合计 52 项，50 通过、2 跳过、0 失败。百度公网与 Chromium 项仍跳过，不能视作浏览器或线上验收。本次五个改动 JavaScript 文件通过语法检查，差异空白检查通过。新增测试初次存在同步异常断言、配置夹具缺字段及迁移夹具正则转义问题，修正后相关测试全部通过；未跳过失败用例。上述为夹具时钟与固定发布运行时验证，没有调用付费服务，不能替代实际性能测量。

## 费用、依赖与合入顺序

Search API 的历史报价为每千次成功请求 0.75 美元；每个查询独立计费，多查询会产生多次请求，客户端取消后已送到上游的请求仍可能产生费用。费用分诊已确认允许默认启用 Search API；沿用 #182 网关现有计数、限流和全公司每北京自然月 10 美元硬上限，到顶即停、不提高额度。不新建、轮换或作废共用钥匙；停用仅关闭网关开关。本轮不执行计费调用。

#182 的网关转发实际位于 PR #184，已核对其内部精确 POST 路径、身份令牌、入口环境、关闭/缺钥匙时的立即拒绝、调用计数及公司每月最多 10 美元限制。#184 已合入 main（469236dba60edb73147fca9269649f24f374df8b），本分支已在该提交上变基。内部网关路径与身份环境沿用抓取端的 `CRYSOUND_DS_TOOLS_BASE`、`CRYSOUND_DS_TOOLS_TOKEN_FILE`，不新增一套地址或身份配置。#185 的 PR #187 已先合入，本分支已在包含该提交的最新 main（5d37efca0c）上变基，保留英文并发 Exa、五秒截止线、费用限制、来源合并及两套计时。修补入口同时注入 search/Exa 计时回调，避免两个替换争用同一处入口。新增 API 与 Exa 同时派发、合并来源和双计时报告用例；四组定向测试共 49 项，47 通过、2 跳过、0 失败。搜索端只在已合入网关的 main 上追加自身改动。
