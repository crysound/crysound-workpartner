## 发布包行为检查

输入为该版本的原始发布包解压目录，不安装依赖、不构建：

```sh
ARTIFACTS_PACKAGE=/path/to/artifacts-package node --test crysound/config/plugin-artifact-opening.test.mjs
node --check crysound/config/plugin-patches.mjs
```

41 项通过。测试加载完整发布模块并在模拟 Host 下挂载其真实作品页；旧代码用例复现归档作品直接打开本机地址。矩阵覆盖会话可用、归档、不存在、加载中，以及侧栏、新标签、当前对话存在或不存在、网页和桌面载体。网页检查预览来源、端口、路径、查询和 fragment；桌面模拟窗口处理器拒绝子窗口并返回空句柄，核对最终本机链接仍交给外部浏览器。另查缺恢复接口、恢复失败、新建失败、侧栏未启用、预览适配器缺失、弹窗被拦截、编辑器启动失败。补丁在原始包和已有标题补丁的 pnpm 临时副本上运行两遍，检查结果不再变化、修改后语法通过且硬链接原文件未改。

已有市场图标补丁的 6 项检查也通过，使用原始 `dshmarket@1.73.12` 发布包。

预装回归的发布包测试通过 `ARTIFACTS_CLIENT=<同一发布包的 lib/client.js> node --test crysound/tests/creation-preinstall.test.mjs` 执行。该测试检查启动后作品页实际中文字典、路由与已存储视图标识、市场资料、语法及重复执行结果，允许共享补丁同时更新作品打开逻辑；不再要求整个客户端只能发生标题替换。修正前已复现旧的全文相等断言失败，修正后两个预装用例均通过，41 项打开行为检查也继续通过。
