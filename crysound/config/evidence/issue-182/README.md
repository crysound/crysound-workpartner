## 取舍与可验证行为

| 场景 | 旧行为 | 本次行为 | 自查 |
| --- | --- | --- | --- |
| 有问题的短正文 | 也请求摘要模型 | 有界 Markdown ≤12000 字符时直接返回，不读摘要凭据 | 发布产物工具执行；断言请求数及凭据读取数均为零，原数字和限制保留 |
| 长正文摘要卡住 | 额外等待最多 15 秒 | 默认 2 秒，超时返回原截断正文 | 虚拟时钟到 2 秒；请求已中止，晚到凭据不补发；原文输出逐字相同 |
| JS 已出正文，但还有持续请求 | 等网络空闲，渲染最多 15 秒 | DOM 就绪后等可见正文，默认 2 秒渲染上限；已有 article/main 80 字正文不启动浏览器 | 真 Chromium 执行 JS，夹具保留未结束的请求，仍成功返回正文并关闭浏览器 |
| PDF、登录、跳转、渲染忙、请求失败或直抓截止 | 原错误或最长等待抓取总时限 | 默认直抓 3000 毫秒后中止；用已有公司凭据向 Responses 请求一次指定 URL 打开，最多 6000 毫秒且受剩余总预算限制 | 真实发布工具注册/执行、固定 Responses 返回；同一原 URL 与问题、来源、一次请求、默认模型与预算、无重定向 |
| 打开失败、未完成、读不到、无真实打开记录或打开了别的 URL | 不适用 | 返回原抓取错误/HTTP 结果，不把模型凭空回答当作正文 | HTTP/网络/解析/拒绝/缺记录/错误 URL/未完成/空输出矩阵 |
| 本人取消、安全拦截、私网地址或含身份信息 URL | 停止/拦截 | 保留限制，不通过模型兜底绕过 | 请求计数为零；两个阶段均测试取消；晚到凭据无请求 |
| 长尾诊断 | 只有工具级时点 | 下载、提取、渲染、摘要和 Codex 打开阶段，关联原调用；跳过与失败分支可汇总 | 发布工具+提供方+真实 Markdown；确定性时钟核对段长和分位、缺失为 null、无正文/地址/密钥；真实 Chromium 核对 render 成功段 |

默认直抓最多 3 秒，Codex 打开最多 6 秒，整个调用工作预算 7.5 秒、外层留 0.5 秒处理余量；打开实际只获剩余预算，不能把 3+6 秒串行耗尽。普通长正文的摘要等待最多额外 2 秒，配置在注册时校验直抓加摘要不能超过总预算。它们是配置上限，不是已测得的线上延迟；浏览器启动/退出、事件循环、真实模型响应与正文质量仍须上线验证。直抓 3 秒覆盖原单典型页面 0.03–2.6 秒的观察，早期报错后的打开上限 6 秒覆盖原单救回页面 4.6–5.9 秒的观察；迟到页面的打开剩余最多约 4.5 秒，以免重新产生长尾。最终阈值必须经真实验收确认。

Codex 打开要求 `/responses` 返回 completed、目标 URL 的完成 `web_search_call` / `open_page` 记录以及 `readable:true` JSON 摘要。上层附原来源链接；不依赖模型自己添加链接。若公司网关过滤打开记录或实际模型不能按此格式输出，兜底会保留原错误，不能将无密钥夹具判作真实页面救回。此项必须在测试账号实测，必要时按真实响应修改本补丁后再交付。
