# 兆华工作伙伴使用说明

先按用户的问题读取这里的说明，再用简短的中文给出入口、动作和完成标志。英文界面可同时给出对应名称。只解释用户问的部分；询问“怎么用”不等于授权你替他连接、安装、发布、改权限或删除数据。

这里说明公司版本的当前行为。用户实际界面与说明不同，先核实运行模式、版本和可见入口，不凭空编按钮，不把开发计划说成已上线。后台自动学习、学习记录与撤销、飞书未连接提醒等，以当前页面是否提供为准。不要用旧的飞书机器人接入向导代替本人授权，不让同事创建应用或提供密钥。

## 连接飞书和飞书项目

- 打开左下角账号菜单里的“设置”（Settings）→“飞书授权”。飞书登录工作伙伴只确认身份，**不代表**伙伴已经获得读取飞书内容的授权。
- 在“飞书”这一行点“连接飞书”（旧版按钮为“连接”），用与当前工作伙伴相同的本人账号完成授权，再回到工作伙伴。状态显示“已连接”才算完成；页面可能同时显示姓名、授权时间。
- “飞书项目”需要**单独连接**，连接飞书不等于连接了飞书项目。在对应行点“连接飞书项目”，打开返回的授权页面；若页面要求授权码，填写工作伙伴显示的那一串。完成后手动回到工作伙伴，等状态变为“已连接”。
- 网页版和云端模式使用云端的项目授权；桌面版本机运行时在桌面版连接项目，两者不能互相替代。项目行可能显示剩余有效期。
- 页面显示未连接、授权过期或账号不一致时，按页面提示连接本人账号。状态无法核实不等于未授权，不要反复发起授权。连接按钮被拦截时，使用页面给出的授权链接，完成后返回设置查看状态。
- 要停止使用授权，在相应行点“断开飞书”或“断开飞书项目”并确认。断开飞书与断开项目是两件事；显示远端撤销待完成时，只能说明已停止使用，不能说远端已撤销。

需要伙伴实际读取日程、文档、任务、项目工作项等时，再读 `company-feishu`，由它选择对应的官方技能。发消息、发邮件、提交审批、删除、修改分享权限前，展示具体对象和完整内容，取得本人对本次操作的确认。不要读取或展示授权令牌。

## 查看、修改和删除记忆

- “设置”→“记忆”（旧版名为“个人记忆”）可以查看已保存的偏好、个人背景和长期项目，以及来源和时间。
- 点“添加一条”填写类型、标题、内容，再点“保存”（旧版字段名为“类别”）；已有条目可点行尾“编辑”修改，新版显示为编辑图标。
- 删除某条：找到这条记忆，点行尾“删除”（新版为删除图标），核对内容后点“确认删除”。删除全部：点“清空全部”，阅读提示后再次点“清空全部”（旧版确认按钮为“确认清空全部个人记忆”）；此处无法恢复。新版入口在列表底部，空列表不显示。
- “使用记忆”（旧版为“使用个人记忆”）开关关闭后，伙伴不再使用长期记忆，也不在对话中保存新条目，已有条目仍保留。关闭开关不等于删除。
- 也可以在聊天中明确说“记住我偏好……”“忘记刚才那条……”“这次别记”。实际保存、遗忘是否完成，以工具返回和设置页为准；不声称所有对话都会自动记住。
- 删除记忆不会删除原聊天记录和已有备份。网页版与桌面版本机运行各存一份，目前不同步；不要承诺删除一端会同步删除另一端。云端会话查看的是云端那份记忆。

## 主动提醒

- 网页版“设置”→“主动提醒”（旧版名为“每天帮我查一次”，英文 Proactive reminders）可查看开关、工作日检查时间和运行记录；改名不重置已有设置或记录。
- 默认关闭，需要先连接本人飞书并获得试用资格，再自行打开。按北京时间在工作日检查未读 @、今天和明天的日程、本人未完成任务；没有新事不打扰，有新事生成摘要会使用模型额度。
- “现在查一次”与定时检查合计每天最多尝试一次，失败当天不自动重试。提醒只放在本人的伙伴对话里，不替你回复或操作飞书；桌面本机模式不单独运行。

## 从市场安装插件

- 打开侧栏“市场”（Market），先看“兆华市场”，查找插件名称、用途和维护人；第三方插件在“第三方”页。
- 打开插件详情，点“安装”（Install），等安装完成；需要配置或启用时按提示进入插件设置。只有安装记录和启用状态都确认后，才说插件已经可用。没有看到刚批准的版本时刷新索引，索引可能缓存十分钟。
- 例如想使用设计能力，先在兆华市场查“兆华设计”。不要说所有官方插件都已预装，也不要把第三方插件当成兆华官方维护的能力。
- 找不到插件或安装出错时，记录插件名称、版本和页面提示，交给工作伙伴管理员核对。不要自行换来源、安装最新版本或改注册表来绕过问题。

## 制作和发布插件

- 在市场中使用“做一个插件”入口进入原生插件创作模式（Creator mode）；若该版本未显示入口，先核实版本，不编造额外的发布按钮。
- 制作完成后，先检查插件用途、配置、权限及打包内容，再按 `publish-zhaohua-market` 技能发布。用户只问发布方法时先解释，不能直接上传。
- 公司市场包使用 `@crysound/` 名称空间。普通同事的插件名称可以自行选择，“兆华”开头的名称留给公司官方插件。
- 上传后是“等待管理员审批”，**不等于已上架**。管理员批准后，其他同事才能在兆华市场看见和安装。已有版本不能覆盖，更新需递增版本。
- 普通包由首个发布者发后续版本；官方插件也可由管理员指定的维护人更新，但每个新版本仍需审批。不要让同事去公共 npm 登录或提供公共 npm 令牌。

## 选择权限档

输入框旁的权限选择器控制**当前会话**；设置里的默认权限用于后续新会话，不会追溯修改已有会话。

| 界面名称 | 含义 |
| --- | --- |
| 仅可查看（Read Only） | 用于查看和分析，写文件等操作受到沙箱与确认限制；以实际弹窗为准。 |
| 工作区内修改（Workspace Write） | 可在当前工作区修改文件；超出工作区等操作会受到限制或要求确认。桌面版默认保持此档。 |
| 完全权限（Full access） | 减少确认并放开沙箱限制，能直接执行更多文件和命令操作。先说明影响，不替用户切换。 |
| 自动审查（Auto review，实验性） | 不使用沙箱；每次工具调用前由模型对照用户要求审查，放行就执行，拒绝则交给用户批准或拒绝。可能误判，也会增加模型用量，**不是安全保证**。网页版新会话在未设个人默认值时使用此档。 |

权限档不替代飞书、市场等业务系统的授权或操作确认；自动审查也不代表已经授权发消息、删除资料或发布插件。权限模式只决定当前运行环境能做什么，不会让云端突然访问电脑硬盘。

## 桌面版与本机文件

- 网页版工作区在云端容器，不能直接读取电脑硬盘。要处理电脑上的文件，可先通过会话附件上传。
- **桌面版本机运行**时，把文件所在文件夹作为工作区打开，或在输入框用 `@` 选取文件；先让伙伴列出准备读取或修改的文件，再给具体任务。文件访问还受当前权限档和操作系统权限限制。
- 如果当前是云端模式，本机目录不会自动变成云端目录。只有客户端实际提供并连接本机文件能力时才按其提示操作；没有入口时使用上传，不编造本机连接按钮。
- 写入、覆盖或删除前先确认目标和影响。只有实际工具明确说明移入废纸篓时才能承诺可从废纸篓恢复，不能把普通命令删除说成可撤销。

## 下载客户端与反馈问题

- 网页版左下角点“下载客户端”，在下载页选对应系统。Mac 只支持 Apple 芯片，另有 Windows 入口；某平台显示“即将推出”表示当前未提供安装包，不承诺已经可下载，不推荐 Intel Mac 包。
- 也可从当前工作伙伴网站的 `/_zp/download` 打开下载页。使用公司提供的下载入口，不搜索来历不明的安装包。
- 登录、授权或安装一直无法完成，联系**公司的工作伙伴管理员**，由管理员转伙伴助理处理。提供问题发生时间、使用的是网页版还是桌面版、操作步骤、页面提示及不含敏感内容的截图；不要发密码、授权码、令牌或客户资料。不要虚构客服邮箱、电话或自动报障入口，也不替同事发消息。
