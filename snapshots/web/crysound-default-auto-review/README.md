# Published Web default Auto authorization

Owner: `crysound/tests/web-auto-review-session.test.mjs`. Run this company-specific owner in the existing pinned Web image using the command in `crysound/tests/evidence/issue-88/README.md`; it is separate from the source Web browser lane because the company patch targets published modules only.

The owner starts the shipped `dsh --profile web` process with an isolated profile, the real auto-review bundle, and only a recorded model adapter. It does not replace permission admission, review processing, approval, shell execution, or Session persistence. The user task and main-model responses come from `session.v4.jsonl`, which is also the complete normalized expected persisted Session. The recorded model attempts an unrequested deletion after the authorized write. `replay.override.json` supplies reviewer responses, which production intentionally excludes from Session logs. Title generation is disabled; the standard Agent preset stays intact. This authored recording tests routing and enforcement, not real-model risk classification.

`system-prompt.expected.md` and `tool-schemas.expected.json` pin readable request contents. Normalization retains all events and payloads, replacing typed identities, runtime locations and clocks only. The test waits for a real remote approval event and its persisted record, checks the original file while the decision is pending, rejects through the public Web protocol, and compares every workspace directory and file against the separately authored `workspace.expected/`. The allowed command must create a file; the denied command must never register a job. No credentials or external network are available.

`AUTO_REVIEW_CAPTURE` may export a candidate Session and sidecars to a separate disposable output directory; it never rewrites this baseline or `workspace.expected/`. Review candidate diffs before updating fixtures. `AUTO_REVIEW_UNPATCHED=1` is a negative control: without the company patch, the initial permission assertion must fail before submitting a task.
